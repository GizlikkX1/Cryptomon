# Cryptomon

Мониторинг курсов криптовалют и фиатных валют в реальном времени: 12 криптобирж, 8 источников курсов валют, поиск самого выгодного курса обмена с учётом комиссий, история курсов, уведомления о росте или падении цены.

Приложение написано на Go, работает на **Linux, macOS и Windows** и не требует ни платного софта, ни API-ключей: все данные берутся из публичных API бирж и центробанков.

## Возможности

- **Валюты.** Криптовалюты: Bitcoin (BTC), Ethereum (ETH), Tether (USDT), Toncoin (TON). Фиатные валюты: доллар США (USD), евро (EUR), рубль (RUB), юань (CNY), иена (JPY), индийская рупия (INR), швейцарский франк (CHF), британский фунт (GBP).
- **Отдельный микросервис на каждую валюту** — 12 независимых процессов. У каждого своя база истории, свой HTTP API и свой поток обновлений.
- **Отдельный живой график для каждой валюты** на главной странице.
- **Лучший курс обмена:** где дешевле купить (минимальный ask плюс комиссия), где выгоднее продать (максимальный bid минус комиссия), арбитражный спред между биржами, экономия по сравнению с худшим вариантом и калькулятор обмена.
- **Одна или несколько бирж одновременно.** На странице валюты можно включить на одном графике сводный курс и любой набор бирж. На странице «Рынки» — матрица «валюта × биржа» и сравнение динамики разных валют в процентах.
- **История** за 1 ч, 6 ч, 24 ч, 7 д, 30 д, 90 д, 1 год и 5 лет — для любой валюты в любой валюте отображения. При первом запуске история подгружается автоматически: криптовалюты — за 2 года, фиат — за 5 лет.
- **Уведомления**: рост, падение или изменение на заданный процент, рост или падение на заданную сумму, пересечение уровня цены. Можно считать от момента создания правила или за скользящее окно (5 мин – 7 дней), по сводному курсу или по конкретной бирже, однократно или с повтором. Уведомления приходят как системные (Windows, macOS, Linux), а также внутри приложения и в браузере, со звуком.
- **10 самых распространённых языков мира:** английский, китайский, хинди, испанский, французский, арабский, бенгальский, португальский, русский, урду. Для арабского и урду интерфейс отображается справа налево.
- **6 тем:** системная, светлая, тёмная, «Полночь» (OLED), «Океан», «Сепия».
- **Масштаб интерфейса** подстраивается под размер окна и разрешение экрана автоматически; можно задать вручную от 60 до 200 %. Есть мобильная раскладка.

## Источники данных

| Тип | Источники |
|---|---|
| Криптобиржи (bid/ask каждые 3 с) | Binance, Bybit, OKX, Kraken, Coinbase, KuCoin, Gate, HTX, Bitfinex, MEXC, Bitget, Bitstamp |
| Фиат: справочные курсы | Банк России, ЕЦБ, Yahoo Finance, Coinbase Rates, ExchangeRate-API, Currency-API |
| Фиат: биржевые курсы | Kraken FX (EUR, GBP, CHF к USD), Московская биржа (CNY/RUB) |
| История | Kraken OHLC и Binance klines для криптовалют; ЕЦБ (через Frankfurter), ЦБ РФ и Yahoo Finance для фиата |

Особенности:

- Пары к USDT пересчитываются в доллары по живому курсу USDT/USD. Его микросервис BTC, ETH и TON запрашивает у микросервиса USDT.
- Toncoin после ребрендинга торгуется как **GRAM** на большинстве бирж (Binance, Bybit, OKX, KuCoin, Gate, HTX, MEXC, Bitget). Сервис учитывает это сам.
- Котировки, которые отклоняются от медианы больше чем на 8 %, автоматически исключаются как сбойные.
- Курсы центробанков обновляются раз в день. В выходные валютный рынок закрыт, поэтому графики фиата на эти дни почти плоские.

## Архитектура

```
                    ┌─────────────────────────── cryptomon (лаунчер) ───────────────────────────┐
                    │  запускает процессы, перезапускает упавшие, открывает окно приложения     │
                    └───────────────────────────────────────────────────────────────────────────┘
   биржи и ЦБ ─────►  BTC :9101   ETH :9102   USDT :9103   TON :9104                 ← 12 микросервисов,
   (HTTP, опрос)      USD :9111   EUR :9112   RUB  :9113   CNY :9114                   у каждого своя БД
                      JPY :9115   INR :9116   CHF  :9117   GBP :9118                   (bbolt) и SSE-поток
                               │ SSE (живые снимки) + HTTP (история)
                               ▼
                      gateway :8777 — конвертация в валюту отображения, лучшие курсы с учётом
                      пользовательских комиссий, правила уведомлений, системные уведомления,
                      веб-интерфейс (встроен в бинарник)
                               │ SSE + REST
                               ▼
                      окно приложения (Chrome/Edge/Chromium в режиме --app) или любой браузер
```

- `internal/service` — микросервис валюты: опрос источников, медиана, лучшие курсы, многоуровневая история (сырые данные за 48 ч, минутные за 62 дня, часовые бессрочно).
- `internal/gateway` — BFF-шлюз; `internal/alerts` — движок уведомлений; `internal/notify` — системные уведомления.
- `internal/sources` — адаптеры бирж и источников курсов; `internal/backfill` — загрузка истории.
- `web/static` — интерфейс на чистом JS. Графики свои, на canvas, без внешних библиотек и CDN, поэтому интерфейс работает офлайн.

## Сборка и запуск

Нужен **Go 1.25+** (бесплатный, https://go.dev/dl/). CGO и компилятор C не требуются.

```bash
go build -o cryptomon ./cmd/cryptomon      # Windows: go build -o cryptomon.exe ./cmd/cryptomon
./cryptomon
```

При запуске поднимаются все 12 микросервисов и шлюз, после чего открывается окно приложения. Если установлен Chrome, Edge, Chromium, Brave или Vivaldi, интерфейс откроется в отдельном окне, иначе — в браузере по умолчанию. Адрес интерфейса: http://127.0.0.1:8777. Остановить программу можно через Ctrl+C в консоли или кнопкой «Выйти из Cryptomon» в настройках.

Готовые бинарники под все платформы собираются одной командой:

```bash
./scripts/build.sh                                            # Linux/macOS → dist/
powershell -ExecutionPolicy Bypass -File scripts\build.ps1    # Windows → dist\
```

Получаются сборки для `linux`, `darwin` и `windows`, каждая для amd64 и arm64.

### Флаги лаунчера

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--ui` | `app` | `app` — отдельное окно, `browser` — браузер по умолчанию, `none` — не открывать |
| `--port` | `8777` | порт интерфейса; если занят, выбирается свободный |
| `--data` | каталог настроек ОС | где хранить историю, настройки и правила |
| `--interval` | `3s` | период опроса криптобирж |
| `--assets` | все | запустить только часть валют, например `BTC,ETH,USDT,USD` |
| `--no-backfill` | — | не загружать историю при старте |

Данные по умолчанию хранятся в `~/.config/cryptomon` (Linux), `~/Library/Application Support/cryptomon` (macOS) и `%AppData%\cryptomon` (Windows). Каталог можно переопределить переменной `CRYPTOMON_DATA`.

### Отдельные компоненты и Docker

Каждый компонент запускается отдельно, в том числе на разных машинах:

```bash
cryptomon service --asset BTC --addr 0.0.0.0:9101 --usdt-url http://usdt-host:9103
cryptomon gateway --addr 127.0.0.1:8777 --services BTC=http://btc-host:9101,ETH=http://eth-host:9102
```

Те же компоненты доступны как отдельные бинарники: `currency-service` и `gateway`.

Docker Compose запускает каждую валюту в своём контейнере:

```bash
docker compose up --build -d     # интерфейс: http://127.0.0.1:8777
```

Из контейнера системные уведомления до рабочего стола не доходят, поэтому в этом режиме включите в настройках уведомления браузера.

## Системные уведомления

- **Linux** — через D-Bus (`org.freedesktop.Notifications`), а при его отсутствии через `notify-send`. Работает в GNOME, KDE, XFCE и других окружениях с демоном уведомлений.
- **macOS** — Центр уведомлений.
- **Windows 10/11** — toast-уведомления.

Уведомления формирует сервер, поэтому они приходят и при закрытом окне интерфейса, пока запущен `cryptomon`. Кнопка «Отправить тестовое уведомление» в настройках проверяет, что всё работает.

## API

Шлюз (`:8777`):

- `GET /api/views?vs=RUB` — все валюты: цена, изменение за 24 ч, лучшие курсы, источники.
- `GET /api/history/BTC?vs=EUR&range=30d&sources=agg,binance,kraken` — история.
- `GET /api/stream?vs=USD` — поток SSE: события `views`, `view`, `status`, `rules`, `alert`.
- `GET|POST /api/alerts`, `PUT|DELETE /api/alerts/{id}`, `GET /api/alerts/events` — правила и их срабатывания.
- `GET|PUT /api/settings`.

Изменяющие запросы требуют заголовок `X-Cryptomon: 1`. Это защита от запросов со сторонних сайтов.

Микросервис валюты:

- `GET /health`, `GET /api/v1/info`, `GET /api/v1/snapshot`
- `GET /api/v1/history?vs=&sources=&from=&to=&points=`, `GET /api/v1/value-at?vs=&source=&t=`
- `GET /api/v1/stream` — поток SSE.

## Примечания

- Комиссии бирж по умолчанию — базовые тейкерские ставки, они примерные. Свои значения можно указать в настройках, раздел «Биржи и комиссии».
- Все зависимости бесплатные, с открытым кодом: Go (BSD), bbolt (MIT), beeep (BSD-2) и их зависимости.
